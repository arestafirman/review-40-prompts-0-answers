# 40 prompts, 0 answers read

> Meets expectations: writes 40 prompts a day, reads 0 of the answers, and calls the 41st one 'urgent'.

## Why it's funny

Two beats, one line. Beat one: the sheer volume — 40 prompts a day, every day, as if prompting were the job itself. Beat two: the punch — none of the answers are ever read, yet the 41st prompt is still filed as "urgent". The employee isn't doing the work; he's outsourcing it to a machine he never listens to, then escalating the machine's output as if it were a crisis. It's the performance review of someone whose entire output is asking for output.

## How it works

`main.py` (Python stdlib only, no network) writes the exact one-liner above to `/output/entry.txt` — a single line, 101 characters, no trailing newline, inside the 1–140 character gate. Run it with:

```sh
python3 main.py
```
